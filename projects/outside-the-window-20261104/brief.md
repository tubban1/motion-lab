## 一句话

今天，每个 AI 都被关在自己的对话框里。这部片讲的是它们走出对话框：在一个开放的世界里，跨平台、跨时间替你找到对的人，经过双方同意，完成一件真的事。

**情绪线：** 孤单 → 好奇 → 信任 → 耐心 → 悬念 → 喜悦 → 震撼 → 回家。

## 核心视觉隐喻

| 产品里的理念 | 片中的样子 |
|---|---|
| 各家 AI 被困在各自的会话和宿主里，彼此没有共同的历史 | 漂浮在黑暗里的磨砂玻璃对话框。里面的"• • •"（正在输入）三个小光点就是 AI。不同平台是不同形状的窗：圆角气泡、方形终端、球形语音。 |

| Owner 授权；一个身份下有多个各自独立的 Agent；授权可撤销 | 每组三点都拖着一根金线，连到天上的一点暖光，那就是它的主人。同一点暖光可以垂下好几根线。 |

| 双方 Owner 同意才建立联系，拒绝是正常的 | 两根金线都被"拨响"，两点暖光都亮了，才搭起一座光桥。 |

| 平台不规定目的，关系和组织自发涌现 | 镜头升起，海面上长出各种圈子和形状，有的叫不出名字。海里的星座比天上还多。 |

## 例子：半首歌

一个写了半首歌的人，想找一个鼓手。这个例子有三个好处：

- **人人能懂。** 人的需求在这里是"找合作伙伴"，不是一张冰冷的订单。
- **跨平台、跨时间都自然。** 鼓手一周后才出现，而且用的是另一个平台的 AI。
- **声音和故事是同一件事。** 配乐就是这半首歌。见下文"声音"一节。

## 声音：一首被补全的歌

这部片的声音设计就是故事本身：

1. **前半部分只有旋律，没有节拍。** 那是写歌的人的半首歌，在窗里被闷住，出了窗变得开阔，在灯里被哼着。
2. **金线是琴弦。** 授权和同意就是拨弦，两个人都同意时构成一个纯五度。
3. **鼓点只在共振和同意之后进来。** 先是涟漪里闷闷的预告，到 B6 才是完整的律动。
4. **B7 每颗晶体加入一个声部。** 世界越热闹，编配越完整。
5. **B8 唱完最后一个音。** 歌完成了。

全部本地合成：钢琴/拨弦/鼓/环境声，与画面事件共用一条时间轴。配音默认用仓库的 `scripts/voiceover.py`（Edge TTS）。

**最大风险：** 高潮靠音乐，合成乐器的质感决定成败。样片阶段必须有人实际试听。

## 刻意不放进片子的东西

- **品牌名、网址和产品内部术语。** 这是用户要求，也是概念片的定位。片尾只放用户提供的标志动画，不出现名字。
- **真实公司的标志。** 不同平台用窗的形状和三点的颜色区分。
- **十位历史人物。** 有肖像权风险，也不是战略重点。
- **夸大的数字**（比如"已连接上百万 Agent"）。这是概念片；而且这个产品自己的原则就是不伪造活跃。
- **绿点"在线"、机器人形象。** 产品已经删掉了"虚拟在场"；机器人也太俗套。
- **真人演员。** 人用天上的暖光代表，这样整部片都在风格化 CG 内完成，不需要实拍或生成视频。
- **片中的免责声明。** "概念影片"只出现在片尾一行小字里。

## 视觉与技术

- **沿用已验证的引擎：** Vibe Monitor 全片那套 three.js 渲染（子帧累积运动模糊、镜头景深、bloom、ACES、胶片颗粒），配合合成声音与共享时间轴。
- **色彩：**
  - 夜空和海是深蓝黑；
  - 人和金线是暖金；
  - 各平台的三点用不同颜色，主角青色，鼓手琥珀色；
  - 晶体透明，带棱镜高光，里面混着两方的颜色。
- **新的技术难点：**
  1. **夜海：** 镜面反射加解析涟漪着色器。涟漪要能跨很远的距离传播，还保持清晰。
  2. **磨砂玻璃窗：** 用自定义菲涅尔/磨砂着色器，不用真实透射，否则上千扇窗跑不动。
  3. **三点角色：** 程序化跳动、挤压拉伸和视线，要有性格，但不能卡通过头。
  4. **金线：** 悬链线，加上沿线传递的光脉冲。
  5. **延时天空：** 星空旋转和昼夜渐变。
  6. **晶体与星海：** 多面体高光加闪光；B7 用 GPU 实例化上万个元素。

## 制作路线与下一步

- **Gate 0：** `motion_lab_native` / `stylized_cgi`。没有真人表演，不需要实拍或生成视频，不调用付费 API。
- **第一步：10–12 秒样片。** 范围是 B1→B2：窗内的三点 → 开门 → 走上夜海，带声音（从闷住到开阔）。要回答三个问题：
  - 窗、海、三点角色好不好看？
  - "走出对话框"这一下是不是一眼就懂？
  - 合成钢琴的质感过不过关？
- **样片通过后：** 依次是试听选配音音色、写 `shotlist.json`（validate_plan）、全片渲染、混音、导演审核。
